# Семинар 6 — Динамический массив (примеры по лекции)

ВНИМАНИЕ: Это **проверенные примеры по лекции**, а НЕ пронумерованные решения домашнего задания.
В приложенных двух PDF нет формулировок ДЗ и требований к именам `01.c`, `02.c`, ...
Когда будет листок с домашним заданием, имена файлов нужно брать оттуда.

## Содержание

- `0dynarray/dynarray.h` — объявления структуры Dynarray и функций.
- `0dynarray/dynarray.c` — реализация динамического массива по страницам 3–7 лекции.
- `0dynarray/main.c` — пример добавления чисел от 0 до 99.
- `0dynarray/test_dynarray.c` — тесты роста вместимости 3→6→12, чтения, записи и освобождения.
- `0dynarray/Makefile` — компиляция и тестирование.
- `separate_compilation/cube.h`, `cube.c`, `main.c` — пример раздельной компиляции со страниц 8–9.

## Сборка на Linux / macOS / MinGW

    cd 0dynarray
    gcc -std=c11 -Wall -Wextra -Werror -pedantic dynarray.c main.c -o demo
    ./demo
    gcc -std=c11 -Wall -Wextra -Werror -pedantic dynarray.c test_dynarray.c -o test_dynarray
    ./test_dynarray

    cd ../separate_compilation
    gcc -std=c11 -Wall -Wextra -Werror -pedantic cube.c main.c -o demo
    ./demo

## Примечания

- Исходный листок содержит опечатки: на странице 2 присваивание третьему элементу должно быть `p[2] = 30;`, а на странице 4 для начальных значений 10,20,30 индексы `set` должны быть 0,1,2.
- В реализации добавлена проверка размера выделения, а `destroy` очищает `size` и `capacity`. Это улучшения безопасности сверх лекционного примера.
- Для сдачи заданий по нумерации семинара необходимо отдельное PDF с условиями домашнего задания.
