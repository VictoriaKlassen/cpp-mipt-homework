# Семинар №5 — Сегменты памяти. Домашнее задание

Готовые решения обязательных задач по листку `tasks_segments (1).pdf`.
Язык: C11. Одна самостоятельная программа на файл `.c`.

| Задание из PDF | Файл |
| --- | --- |
| 1(a)–1(i) — объекты в куче | `01a.c` … `01i.c` |
| 2 — геометрическая прогрессия | `02.c` |
| 3 — конкатенация | `03.c` |
| 4 — динамические строки и сортировка файлов | `04.c` |
| 5 — сегменты | `05.txt` |
| 6 — сортировка с компараторами | `06.c` |
| 7 — подсчёт с предикатом | `07.c` |
| 8 — сортировка функций | `08.c` |
| 9 — сумматор | `09.c` |
| 10(a) — анализ BSS | `09a.txt` |
| 10(b) — куча | `09b.c`, `09b.txt` |
| 10(c) — стек | `09c.c`, `09c.txt` |

**Важно о нумерации:** в листке ДЗ последний пункт называется «Задача 10»,
но преподаватель прямо требует для подпунктов файлы `09a.txt`, `09b.c`,
`09b.txt` и `09c.txt`. Здесь сохранены **именно эти названия из PDF**.
Для пункта 10(c) приложен также исходник `09c.c`, необходимый для проверки.

## Как компилировать

```bash
gcc -std=c11 -Wall -Wextra -pedantic 01a.c -o task
./task
```

Аналогично для `01b.c`–`09.c`.

Задача 4 — сортировка строк из файла. Пример:

```bash
gcc -std=c11 -Wall -Wextra -pedantic 04.c -o line_sorter
./line_sorter input.txt result.txt
```

В `04.c` собраны все семь подпунктов задачи 4: `get_test_strings`,
`print_strings`, `get_sizes`, `load_lines`, `destroy_strings`, `sort_strings`,
программа `line_sorter`. В `main` используется сортировка файла; вспомогательные
функции доступны для прямых вызовов и отдельного тестирования.

## Задание 10 — важная оговорка

`09b.c` запрашивает **1 ГБ памяти в куче**, а `09c.c` — **1 ГБ в стеке**.
Второй вариант при обычном размере стека, скорее всего, аварийно завершится.
Эти программы **не запускаются в автоматических тестах**. Файлы `.txt`
содержат ожидаемое объяснение поведения на типичных ОС, а не выдуманные
результаты конкретных измерений. Для задания нужно отдельно проверить
потребление памяти на своём компьютере.

В задании 5 расположения в `.txt` соответствуют обычной модели памяти
современных систем: фактическое расположение объектов зависит от сборки,
операционной системы и компилятора.
