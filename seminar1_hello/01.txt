2) В scanf передаётся значение переменной a вместо её адреса. Нужно написать scanf("%i", &a). неопределенное поведение
3) В условии if используется оператор присваивания = вместо оператора сравнения ==. Нужно написать if (a == 10).неопределенного поведения нет
4) В строке scanf после %i стоит лишний пробельный \n. Из-за этого scanf после считывания числа продолжает ждать следующий непробельный символ. Нужно написать scanf("%i", &a).неопределенного поведения нет
5) После if нет фигурных скобок, поэтому к if относится только первая инструкция printf("%i\n", a). Инструкция printf("Positive\n") выполняется всегда.неопределенного поведения нет
6) После if (a > 0) стоит лишняя точка с запятой. Точка с запятой является пустой инструкцией, она является телом if, те printf("Positive\n") выполняется независимо от условия. неопределенного поведения нет
7) В цикле while не изменяется переменная i.Она всё время равна 1, поэтому условие i <= 10 всегда истинно и получается бесконечный цикл.неопределенного поведения нет
8) После while (i <= 10) стоит лишняя точка с запятой. Она является пустым телом цикла. Так как i внутри этого цикла не изменяется, получается бесконечный цикл. неопределенного поведения нет
9) Переменная sum объявлена, но не инициализирована. При выполнении sum += i используется неопределённое начальное значение sum. Нужно написать int sum = 0.неопределенное поведение
